| Feature | How to Access | Professional Use Case |
|---------|--------------|----------------------|
| **GPT-4o** | Default model (limited free; unlimited Plus) | General professional tasks |

| **Browse with Bing** | Enabled in some plans/regions | Web search within ChatGPT |
| **Shared Links** | Share conversation URL | Collaborate on AI-generated content |

**ChatGPT Workflow Example — Analyzing a Business Report:**

```
Step 1: Open ChatGPT → New Chat
Step 2: Click the paperclip icon → Upload your PDF (e.g., Annual Report)
Step 3: Type your analysis request:

"You are a financial analyst. I have uploaded a company's annual report.
Please:
1. Summarize the 3 key business highlights in bullet points
2. Identify 3 risks mentioned by management
3. Extract the 5 most important financial figures (revenue, profit, etc.)
4. Give me 2 questions I should ask the CFO at the next earnings call"

Step 4: Review, refine with follow-up questions
Step 5: Export or copy the structured output
```

## 3. The PACE+S Framework — Evaluating Any AI Tool

Before adopting any new AI tool professionally, evaluate it against this framework:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    THE PACE+S FRAMEWORK                                     │
│                    For Evaluating AI Tools                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  P — PURPOSE                                                                │
│      ▸ What specific problem does this tool solve for me?                   │
│      ▸ Does it address a real, recurring task in my workflow?               │
│      ▸ Is there a simpler way to do this task without another tool?         │
│                                                                             │
│  A — ACCURACY                                                               │
│      ▸ How reliable are the outputs for my specific use case?               │
│      ▸ What is the hallucination risk for this type of content?             │
│      ▸ Does the tool cite sources, or does it generate unsupported claims?  │
│      ▸ How do experts in this domain rate the quality?                      │
│                                                                             │
│  C — COST                                                                   │
│      ▸ Is the free tier sufficient for my typical use volume?               │
│      ▸ What are the usage limits that matter (messages/day, words/month)?   │
│      ▸ What specific features does paid unlock that I actually need?        │
│      ▸ What is the total cost at my projected usage level?                  │
│                                                                             │
│  E — ECOSYSTEM                                                              │
│      ▸ Does this integrate with tools I already use daily?                  │
│      ▸ Can I export outputs in formats I can use (docx, pptx, CSV, PDF)?   │
│      ▸ Does it connect to my data sources (Drive, SharePoint, CRM)?        │
│      ▸ Will my team be able to collaborate on AI outputs?                   │
│                                                                             │
│  S — SECURITY & PRIVACY                                                     │
│      ▸ Where is my data stored? Which country? Which cloud provider?        │
│      ▸ Is my input used to train future versions of the model?              │
│      ▸ What is the data retention policy? How long are prompts stored?      │
│      ▸ Is this tool compliant with my organization's data policy?           │
│      ▸ Is there an enterprise/team version with enhanced privacy controls?  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

**Applying PACE+S — Example Evaluation:**

**Scenario:** A marketing manager at a healthcare company wants to evaluate Jasper (AI writing tool):

| Criterion | Evaluation | Decision |
|-----------|-----------|---------|
| **Purpose** | Produces marketing copy at scale — yes, relevant | ✓ Proceed |
| **Accuracy** | Good for marketing language; no clinical claims needed | ✓ Proceed |
| **Cost** | $49/month; team needs 5 seats = $245/month | ⚠️ Evaluate ROI |
| **Ecosystem** | Integrates with WordPress, HubSpot, Google Docs | ✓ Proceed |
| **Security** | Healthcare data handled: need to check HIPAA compliance | ⚠️ Requires legal review — may not allow patient context |

**Result:** Useful for general marketing content; legal must confirm compliance before using any patient-adjacent content.

## 5. Industry Case Study: Duolingo's AI Transformation

**Company:** Duolingo — language learning app, 500M+ users across 40+ languages

**The Content Problem at Scale:**

Traditional content creation for a language app requires:
- Native speakers to write thousands of practice sentences
- Linguists to verify grammar accuracy in each language
- Designers to create engaging lesson structures
- This must be personalized to each user's proficiency level

Duolingo had 40+ languages, each needing thousands of unique exercises. Human-only content creation simply could not scale.

**The AI Solution — GPT-4 Integration:**

```
Before GPT-4:
  Content team creates sentences manually → batch tested → deployed
  Time per exercise: 15–30 minutes (human drafting + review)
  Monthly new exercises: ~500 across all languages

After GPT-4:
  AI generates sentence candidates at any difficulty level
  in any of 40+ languages → reviewed by linguistic team → deployed
  Time per exercise: 3 minutes (AI draft + human review)
  Monthly new exercises: 50,000+ across all languages
```

**What Duolingo's GPT-4 integration does:**

1. **Generates practice sentences** at precisely the user's level (A1 to C2)
2. **Explains grammar rules** in the user's native language, not just English
3. **Creates conversation scenarios** for the speaking practice feature
4. **Powers "Lily" the AI tutor** — responds to user questions in real time
5. **Personalizes error explanations** based on the specific mistake made

**Results:**
- Content creation cost reduced by **60%**
- **100x more personalized** content available per user
- User engagement (time in app) increased **40%**
- Subscription revenue grew **47% year-over-year**
- Linguistic team headcount did NOT decrease — experts now do high-value review and quality control

**Lesson for this course:** Duolingo is not an "AI company" — it is a language learning company that uses AI as a force multiplier. Your goal is to become the Duolingo of your industry — using AI to multiply your own output and expertise.

## 9. Interview Questions — Session 4

**Q1:** *"What AI tools do you use regularly, and why did you choose them?"*

**Strong Answer Framework:**
- Name specific tools (not just "ChatGPT")
- Describe the specific task each handles
- Explain the outcome each enables
- Show that you've evaluated alternatives

*Example:* "For general writing and analysis, I use ChatGPT because of its versatility and file upload capability. For research where I need current information with citations, I use Perplexity AI. For creating presentations quickly, I use Gamma.app. I chose these after comparing alternatives using the PACE+S framework — they match my workflow, are accurate enough for my use cases, and fit within my budget."

**Q2:** *"How is Microsoft Copilot different from ChatGPT?"*

**Strong Answer:**
"Both are powered by GPT-4o at their core, but they differ in three key ways. First, Microsoft Copilot has live web access by default — it can answer questions about today's news, current prices, and recent events, with source citations. ChatGPT's free version has a knowledge cutoff. Second, the Microsoft 365 enterprise version of Copilot integrates directly into your emails, documents, calendar, and Teams — it can summarize your actual emails or draft a document based on your own files. ChatGPT is a standalone tool. Third, Copilot's responses always include hyperlinked sources, making it easier to verify information."

**Q3:** *"What considerations would you make before recommending an AI tool to your organization?"*

**Strong Answer:**
"I would use the PACE+S framework: Purpose — does it solve a real, recurring business problem? Accuracy — are outputs reliable enough for our use case, and what is the hallucination risk? Cost — does the ROI justify the subscription or implementation cost? Ecosystem — does it integrate with our existing tools (Microsoft 365, Google Workspace, Salesforce)? Security — where is our data stored, is input used for model training, and does this meet our regulatory requirements (GDPR, HIPAA, etc.)? The security consideration is especially critical in healthcare, legal, and financial services."
